## Self-certifying return

Poincaré ε-return, provability in a named arithmetic S, and self-certifying “this life returns” claims are written out as separate sentences. The box means Prov_S. Gödel’s second theorem and Löb’s theorem limit self-certification inside S. They do not refute recurrence, and incompleteness is not an argument for Poincaré. Undecidability of a recurrence query is recorded as a fact about the decision problem.
